Description

Reversing a Linked List

Easy

The task is to reverse a linked list and return the reversed head. 

        Input: head: 1 -> 2 -> 3 -> 4 -> NULL
        Output: head: 4 -> 3 -> 2 -> 1 -> NULL
        Explaination: Since head was at 1 it came at 4 after reversing
                
        Input: head: 2 -> 7 -> 10 -> 9 -> 8 -> NULL
        Output: head: 8 -> 9 -> 10 -> 7 -> 2 -> NULL
        Explaination: Since head was at 2 it came at 8 after reversing

Constraints:

  • 1 <= number of nodes, data of nodes <=105
